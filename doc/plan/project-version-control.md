# 项目版本控制

状态：尚未实现，准备实现。

## 范围

在 Drawer 项目标题右侧增加版本控制入口，以 Bottom Sheet 只读展示当前项目 Git 状态、提交历史树、提交内容和 Diff。

## 行为要求

- 后端使用现有 arm64 PRoot Ubuntu 中的官方 `git` CLI；缺失时在明确进度和错误提示下安装，不把 Git 实现嵌入 APK。
- 所有命令使用固定参数列表和经过项目根目录校验的路径，不拼接用户输入 shell 脚本。
- 状态页区分未跟踪、未暂存和已暂存状态；支持查看当前未暂存 Diff。
- 历史页按拓扑顺序展示有限数量的提交树；点击提交显示作者、时间、摘要、变更文件和 patch。
- 解析使用 `--porcelain`、NUL 分隔和固定 locale 的机器格式，不解析面向用户的本地化 Git 输出。
- Git 进程、协议解析、领域模型、列表适配器和 Bottom Sheet 分离；进程与文件读取均不在主线程。
- 第一版不实现提交、暂存、分支切换、合并、推送或凭据管理。

## 验收

- 非 Git 项目、未安装 Git、空历史、无改动和命令失败均有明确空状态。
- 包含空格、非 ASCII 和重命名路径的状态可正确解析。
- 提交树、提交详情和未暂存 Diff 可查看，超长输出有确定上限且不会阻塞界面。
