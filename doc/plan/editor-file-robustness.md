# 编辑器文件健壮性

状态：尚未实现，准备实现。

## 范围

完善现有文件打开与保存链路，不改变项目存储根目录和原子保存约束：

1. 外部文件内容变化冲突检测。
2. 原始换行风格保留。
3. 二进制内容探测。
4. 大文件加载保护。

## 行为要求

### 外部修改冲突

- 已打开文件被外部修改时，不得静默覆盖。
- 当前标签 dirty 时，提示重新加载或保留编辑内容。
- 当前标签未 dirty 时，可以安全刷新磁盘内容，并恢复合理的光标与滚动位置。

### 换行风格

- 打开文本时识别主要换行风格。
- 保存时保留原始换行风格；新建文件使用项目统一默认值。
- 不为换行转换绕过 `StorageUtils.writeTextAtomic`。

### 二进制探测

- 不可安全作为文本编辑的内容应在载入 Sora Editor 前识别。
- 二进制文件显示可理解提示，不强制解码，不创建可误保存的文本标签。

### 大文件保护

- 文件读取和判定在后台执行，不阻塞主线程。
- 超过明确上限的文件在完整载入前提示用户，避免移动设备无界内存占用。
- 上限应集中定义并覆盖边界测试，不能散落在 Activity 中。

## 验收

- 外部修改与 dirty 内容冲突时，用户选择前磁盘或编辑内容均不丢失。
- CRLF 和 LF 文件经过无关编辑并保存后仍保持原换行风格。
- 二进制文件不会以乱码载入或被文本保存链路覆盖。
- 大文件保护在阈值边界行为确定，且文件读取不阻塞主线程。
