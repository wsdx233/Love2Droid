# 项目最近打开时间

状态：尚未实现，准备实现。

## 范围

为项目元数据增加最近打开时间，并在项目管理界面展示。该字段只描述项目最近一次成功打开的时间，不参与 project id、目录排序以外的存储边界或 Play 校验。

## 行为要求

- 项目成功打开后更新时间；打开失败时不写入。
- 更新时间必须通过现有项目仓库和原子写入路径完成，不由 Activity 直接覆盖元数据文件。
- 旧项目缺少该字段时仍能加载，并显示明确的缺省状态。
- 项目列表显示可读时间；排序规则如采用最近打开优先，应保持稳定，并为无时间项目定义确定位置。
- 重命名项目保留最近打开时间；新建项目在首次成功打开后写入。

## 验收

- 打开项目、重启应用后，最近打开时间仍然存在并正确展示。
- 打开失败不改变已有时间。
- 缺少字段的旧元数据与新增字段兼容。
- 重命名不丢失时间，项目列表排序在相同时间和缺省值下保持确定。
