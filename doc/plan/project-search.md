# 项目搜索

状态：尚未实现，准备实现。

## 范围

在 Drawer 项目标题右侧增加搜索入口，以 Bottom Sheet 提供“文件”“文本”“符号”三个标签。

## 行为要求

- 文件和文本搜索在后台遍历当前项目；所有命中路径 canonicalize，并限制在项目根目录内。
- 文件搜索匹配项目相对路径；文本搜索显示相对路径、行号和摘要；两者支持普通文本和 Java 正则表达式。
- 跳过 `.git/`、隐藏的产品元数据和二进制文件；限制单文件大小、命中数量和摘要长度，取消旧查询，禁止递归 I/O 阻塞主线程。
- 符号搜索优先使用 LuaLS `workspace/symbol`；LuaLS 不可用或无语义结果时使用本地 Lua 标识符索引，并在结果中区分语义结果与本地降级结果。
- 点击文件、文本或符号结果均在应用内打开项目文件并定位，不启动外部 Intent。
- 搜索引擎、LSP 适配、结果适配器和 Bottom Sheet 分离；`EditorActivity` 只提供当前项目和打开位置回调。

## 验收

- 三个标签可以切换并取消过期查询。
- 普通与正则文件/文本查询结果稳定、排序确定，项目外路径无法进入结果。
- LuaLS 在线时返回 workspace symbol；离线时符号标签仍能给出明确标记的本地结果。
- 大文件、二进制文件和无效正则不会导致崩溃或主线程卡顿。
