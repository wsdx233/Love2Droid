# 编辑器搜索与替换

状态：尚未实现，准备实现。

## 范围

替换 Sora 默认 `beginSearchMode()` 入口，提供独立的编辑器搜索控件，不把搜索 UI 和状态继续堆入 `EditorActivity`。

## 行为要求

- 搜索栏最左侧为展开按钮；展开时旋转并显示替换输入行，收起时恢复纯搜索模式。
- 搜索支持普通文本和 Java/Sora 正则表达式；正则开关状态清晰可见，无效表达式显示错误且不执行搜索。
- 提供上一项、下一项、关闭；替换模式提供替换当前项和全部替换。
- 切换文件标签时搜索控件保留查询模式，但对新文档重新提交查询；关闭时调用 `stopSearch()` 并释放输入法焦点。
- UI 文案使用字符串资源；搜索和替换继续复用 Sora `EditorSearcher`，不重复实现文本匹配器。

## 验收

- 普通查询和正则查询均能前后定位。
- 展开按钮旋转，替换框与替换操作随展开状态显示或隐藏。
- 正则替换支持捕获组回引；非法正则不会崩溃或残留旧结果。
- 搜索控制逻辑位于独立组件，`EditorActivity` 只负责生命周期接线。
