# 界面与交互设计

本文记录当前产品界面和用户可见行为。系统边界见 [architecture.md](architecture.md)；尚未实现的增强只记录在 [`plan/`](plan/) 中。

## 应用品牌与启动图标

- Love2Droid 使用 Android 机器人抱着 LÖVE 标志的倾斜拥抱造型：Android 绿色、LÖVE 原有粉蓝配色、暖白背景；品牌与上游项目的关系及素材署名见 [reference.md](reference.md#应用品牌与-readme-素材)。
- Android 8.0 及以上使用前景/背景分层的自适应图标，主体位于 108dp 画布中心的 66dp 安全圆内；圆形、圆角方形等裁切不应截断触角、手臂或 LÖVE 标志。Android 13 及以上额外提供透明镂空的单色图层，由支持主题图标的桌面着色。
- Android 6.0/7.x 使用同一造型的矢量兼容图标；圆形图标入口复用同一资源。新品牌仅应用于 `normal` 产品，不改变导出游戏的默认 LÖVE 图标或用户自定义项目图标。
- [英文 README](../README.md) 与[中文 README](../README_CN.md) 使用同一 SVG 品牌图；`images/icon.png` 是对应的 512px 栅格导出。README 截图为用户提供的真实界面记录，不用新品牌重绘截图内容。

## 主界面

```text
┌──────────────────────────────────────────┐
│ ☰  项目名                    ▶  ⋮         │ AppBar
├──────────────────────────────────────────┤
│ [main.lua ×] [未命名 • ×]          [+]   │ 标签栏
├──────────────────────────────────────────┤
│                                          │
│              Sora CodeEditor             │ 编辑区
│                                          │
├──────────────────────────────────────────┤
│ ← → fun ( [ { " = : . , _ + - …         │ 快捷输入栏
└──────────────────────────────────────────┘
```

- 左上角导航按钮打开或关闭文件浏览器；Play 启动当前项目；overflow 打开项目管理。
- 竖屏时 Drawer 覆盖编辑区并显示 scrim；横屏允许 Drawer 与编辑区同时显示。
- AppBar 和 Drawer 避开状态栏 inset；输入法弹出时编辑区缩小，快捷输入栏停靠在输入法上方。
- 横竖屏旋转由 Activity 接管配置变化，编辑器标签、未保存文本、终端标签和当前目录保持不变。

- 产品图标统一使用 Material 矢量图标，不使用 `android.R.drawable` 旧图标；AppBar 图标使用与顶栏背景相配的黑/白前景，弹出菜单内的图标跟随亮暗主题前景色。
- 应用主题设置提供亮色、暗色和跟随系统三种模式，作用于普通应用界面；编辑器主题独立提供三种模式，代码区、文件/终端共用标签栏、编辑器辅助栏和选区浮动操作菜单使用对应编辑器配色。
- 欢迎页、文件侧栏及多选操作栏、项目管理、设置、模型设置和组件安装页面使用应用主题的背景及 Material 语义前景色；亮色页面背景保持纯白，暗色使用深色背景。系统导航栏背景和图标同时适配，不能出现深色文字配深色背景或浅色文字配固定白底。

## 无项目欢迎页

- 完成或跳过首次环境安装后，若没有可恢复的当前项目，编辑器停留在欢迎页，不再自动跳转项目管理；已有可恢复项目仍按原流程打开。这里的“无项目”指尚未打开项目，不是新建模板中的“空项目”。
- 页面居中显示现有 App 图标、“欢迎使用 Love2Droid”及无表情符号的引导文案，下方依次提供“导入项目”“新建项目”“打开项目”；新建为实心主按钮，导入和打开为描边按钮。
- “导入项目”直接调用现有 `.love` / `.zip` 项目导入流程并打开标准 DocumentsUI；取消选择返回欢迎页，成功后打开导入项目，失败沿用项目管理错误提示。“新建项目”直接进入现有模板与信息填写页；“打开项目”进入项目管理列表。新建或选择项目后回到同一编辑器，继续使用原有项目切换与未保存内容保护。
- 欢迎内容随应用亮暗主题切换，空间不足时可纵向滚动；无项目且无标签时隐藏空标签栏。已有项目但没有活动标签时，显示文件编辑引导和“打开文件 / 新建文件”，不展示无项目的三个入口。

## 应用更新

- 设置中的“应用更新”集中展示当前版本、“自动检查更新”开关和“检查更新”按钮；自动检查默认开启，关闭状态持久化，手动检查不受开关影响。
- 每次应用进程冷启动时检查一次 GitHub 最新正式 Release；切换页面、旋转或普通后台恢复不重复请求。不显示自动检查进度，无更新和失败均静默，不在后台定时轮询。
- 仅远端版本严格高于当前版本时弹出 Dialog，展示当前版本与最新版本，提供“稍后再说”和“前往下载”。请求在后台完成时保留结果，待更新提示宿主页面恢复到前台后再显示；当前启动内不重复弹出。
- 手动检查期间按钮显示“正在检查更新…”并禁止重复点击；无更新、无正式 Release 和检查失败有明确反馈，失败后可以再次检查。
- “前往下载”通过浏览器打开该版本的 GitHub Release 页面，由用户选择普通版或离线版安装包；不自动下载安装，也不修改项目文件或已有工具环境。

## 文件浏览器

Drawer 使用 `RecyclerView` 展示当前目录的直接子项，不渲染可展开树：

- 文件夹优先，名称按不区分大小写排序。
- 子目录首行显示 `..`；项目根目录不显示该项。
- 行内显示图标、名称和简介。文件简介包含语言/类型和可读大小；文件夹显示直接子项数量。
- 顶部显示项目名和项目内相对路径；项目标题右侧依次提供项目搜索、版本控制和项目属性入口，目录菜单提供新建文件、新建文件夹、导入、导出、粘贴和刷新。项目管理页面提供“导入 `.love` / `.zip` 项目”；项目长按菜单提供“导出为 `.love`”。
- 完整路径、时间戳和权限等低频信息放入“详情”，不挤占行内空间。

| 手势 | 行为 |
| --- | --- |
| 单击文件夹 | 进入目录 |
| 单击 `..` | 返回项目内上级目录 |
| 单击文件 | 打开文件或切换到已有标签 |
| 长按普通项目 | 打开操作菜单，不自动进入多选 |
| 水平滑动普通项目 | 选中该项并进入多选；不影响垂直滚动 |
| 多选时单击 | 切换当前项选中状态，并将新选中项作为后续区间端点 |
| 多选时水平滑动另一项 | 按当前可见顺序选择锚点到该项的闭区间 |
| 浏览器内返回 | 依次退出多选、返回上级目录、关闭 Drawer |

长按菜单提供打开、重命名、复制、剪切、删除和详情；文件夹额外提供“导入”和“导出”，文件提供“导出”。“导入”先选择导入文件或文件夹，再通过 SAF 选择外部项目，并将文件或目录本身复制到目标目录；导出文件夹时通过 SAF 选择外部目标目录，直接复制完整目录，不打包 ZIP；导出文件通过 SAF CreateDocument 选择目标文件。进入多选后，Drawer 底部用快速非线性动画显示纯图标操作栏；全选、反选和取消选择按钮均提供无边框波纹反馈。多选操作只作用于选中项；`..` 不可选择。新建、重命名和粘贴必须拒绝非法名称、重名和路径越界，删除前需要确认。

## 项目搜索与版本控制

- 项目搜索使用 Bottom Sheet 的“文件”“文本”“符号”三个标签。文件和文本支持普通查询与正则查询；结果显示项目相对路径，文本结果额外显示行号和摘要。
- 符号结果明确标记 LuaLS 语义来源或本地降级来源。点击任何结果都在应用内打开项目文件并定位。
- 版本控制使用 Bottom Sheet 的“状态”和“历史”标签。状态按 VS Code Source Control 结构分为“已暂存”和“更改”两组；文件行可打开对应暂存/未暂存 Diff，也可单独暂存或取消暂存，顶部提供全部暂存、全部取消暂存和两类完整 Diff。
- 状态页提供提交消息输入框和提交按钮；只有存在已暂存文件时允许提交。没有仓库时可直接初始化；Git 写操作、递归文件 I/O 和 Diff 读取均在后台执行，失败时保留页面并显示错误。
- Diff 使用自定义 unified patch 列表渲染：新增行绿色、删除行红色、hunk 标题使用主题色，并显示旧/新行号；历史提交详情沿用同一渲染器。
- Git 不提供分支、合并、推送或凭据操作。
- 项目搜索栏同时提供标准 Material 搜索图标按钮和正则开关；输入变化继续防抖搜索，点击搜索按钮立即提交当前查询。

## 编辑器

- 应用顶栏与状态栏在亮色模式下使用纯白背景和黑色标题、返回/导航及 action 图标，在暗色模式下使用纯黑背景和白色前景；不使用主题色作为顶栏背景。
- 每个文件标签独立维护文本、光标/选区、滚动位置、语言、原始换行风格和 dirty 状态；“只读”仅作用于当前标签，关闭标签或应用后不保留。
- 单击非活动标签切换内容，单击活动标签打开标签操作菜单；长按任意文件、终端或 DSH 标签正文也打开同一菜单，不先切换活动标签，松手不再触发单击。
- 标签操作菜单以触发的标签为目标，提供关闭当前、其他、全部、左侧及右侧标签；边缘标签禁用不存在方向的操作，未保存文件继续沿用保存、放弃和取消流程。独立的关闭按钮仍直接关闭对应标签。
- 文件首次打开在后台读取，使用 UTF-8 严格解码；超过 5 MB、二进制或非 UTF-8 文件不载入 Sora Editor，并给出可理解提示。
- 文件标签保存加载时记录磁盘大小和修改时间；外部删除或修改会被识别。clean 标签自动重新载入文本；dirty 标签在切换、保存或恢复时提示重新载入或保留编辑内容，确认前不覆盖磁盘内容。
- dirty 标签显示圆点。切换、进入后台和 Activity 销毁前保存可落盘文件；保存失败或外部冲突时保留 dirty 状态并提示。
- 底部快捷输入栏可横向滚动；点击符号会替换选区或插入光标处，并保持编辑器和输入法焦点。AppBar 中的“符号栏”开关控制其显示状态并跨重启保存。
- 文件标签活动时，AppBar 直接显示“保存”和“撤销”图标，窄屏时优先压缩标题；“另存为”使用 Google Material Symbols 标准 `save_as` 图标。保存使用原子写入并恢复打开文件的 LF/CRLF/CR 换行风格：项目文件受项目边界约束，DSH 打开的外部文件保存回原路径并受应用存储边界约束；“另存为”仍选择当前项目根目录中的文件名。
- 顶栏及 overflow 的文件操作（保存、撤销、另存为、查找和替换、自动换行、符号栏、只读、LuaLS 悬浮信息）仅在文件标签活动时显示；终端、OMP、DSH 和无标签页面隐藏这些操作，切回文件恢复显示及对应勾选状态。只读文件禁用撤销，但仍允许保存、另存为及关闭只读；无当前项目时，已有路径的文件仍可保存回原位置，未命名文件的保存和所有文件的另存为禁用。
- Play 与 Android 打包仅在存在当前项目时显示，在终端、OMP、DSH 及项目内无标签页面仍可使用，目标始终为当前项目；不随文件所在目录或长按标签改变。新建菜单、设置和项目管理保持全局可用，不把同一个操作 ID 或图标复用成不同含义的功能。
- DSH 标签活动时，顶栏直接显示独立的“后退”和“刷新”操作；其他类型标签及无标签页面不显示。后退作用于当前 DSH 页面的浏览历史，无历史时禁用；刷新重新加载当前页面，而非重置到首页，仍在等待服务地址时沿用原服务启动流程。
- Lua 及已注册语言使用 TextMate 高亮；当前注册覆盖 Lua、Java、Kotlin、JavaScript/TypeScript、Python、HTML、XML、Markdown、JSON、CSS、Shell、TOML 和 GLSL（含 `.vert`/`.frag`），没有匹配 grammar 时以纯文本打开并给出可理解的错误。
- 编辑器主题从独立的 TextMate 主题注册表加载，亮色使用 `quietlight`，暗色使用 `darcula`，跟随系统按系统明暗选择。
- LuaLS 已连接时，长按 Lua 标识符仍按编辑器默认行为选择单词；在文本选区操作浮动菜单中，完整符号选区会额外显示“转到定义”和“查找用法”两个图标按钮。多定义和用法结果使用可滚动 Bottom Sheet 展示项目相对路径、行号与代码摘要，点击结果在应用内打开标签并定位。
- 选区浮动菜单中的定义和用法按钮使用当前 `EditorColorScheme` 的背景和图标颜色，点击时保存符号位置后再关闭菜单并执行导航。
- LuaLS 悬浮信息中的项目 `file:` 链接由编辑器内部处理，不交给系统 `Intent`；项目外或无效路径只显示可理解错误，点击悬浮窗口外的其他区域会关闭悬浮窗口。AppBar 中的“LuaLS 悬浮信息”开关控制浮窗并跨重启保存。
- AppBar 文件菜单中的“查找和替换”打开独立搜索栏。左侧展开按钮控制替换行并旋转；普通/正则模式均支持上一项、下一项，展开后支持替换当前项和全部替换。非法正则显示输入错误且不沿用旧结果；切换标签会对新文档重新提交查询。

## 项目属性与 Android 打包

- Drawer 项目标题右侧的项目属性入口使用可滚动 Bottom Sheet，编辑图标、应用名称、Android 包名、版本名称、版本代码、屏幕方向、常用权限和自定义权限。自定义权限只接受完整权限名，不接受 XML。
- 图标通过系统图片选择器导入；无自定义图标时使用 LÖVE 默认图标。
- AppBar 文件菜单中的“打包 Android APK”先保存可落盘标签，再显示打包 Bottom Sheet。面板展示发布属性和当前签名 SHA-256 指纹；没有签名时首次打包自动创建项目独立签名，也可导入带密码的 RSA/EC PKCS#12。
- 打包阶段依次显示 `.love` 快照、APK 组装和签名状态。成功后提供“分享 APK”和“安装 APK”；分享和安装只使用临时 Content URI，Android 8.0 及以上缺少未知来源授权时跳转系统设置。
- 打包开始前再次从项目仓库读取发布属性，确保属性面板保存后的应用名、包名、版本、方向和权限进入成品 APK。


## 标签

- 文件和终端共用横向标签栏；同一 canonical 文件路径最多打开一个文件标签。
- DSH Web 中点击文件时，已打开则切换到该标签，否则新建文件标签。当前项目外但应用可访问的文件也按独立标签打开，不切换项目、不移动文件、不加入当前项目文件树；未保存内容不会被重新读取覆盖。关闭应用后，外部文件引用与未保存文本随工作区恢复。
- 此集成只接管 DSH Web 的文件打开动作，不替换普通终端的 `xdg-open`；目录与网页打开仍沿用 DSH 原行为。二进制、非 UTF-8、超限、已删除或无法访问的文件显示错误，不创建伪装成成功的空标签；不支持安全消息桥的旧 WebView 提示更新 Android System WebView。
- 标签栏高度为 `24dp`，宽度随文件名自适应；文件名超过 15 个字符时显示前 15 个字符和 `...`。
- 标签、关闭按钮和新建按钮均提供波纹反馈。活动标签底线使用主题色，其他标签使用灰色。
- 标签栏背景、标签文字、分隔线、关闭及新建图标使用当前编辑器颜色方案；新建、关闭、切换或刷新标签时不得恢复固定白底，也不能混用应用主题的文字色与编辑器背景。
- 未保存标签显示 dirty 圆点；关闭 dirty 标签时提供保存、不保存、取消。
- 最右侧固定 `+` 按钮用于创建未命名文档。未命名文档首次保存或关闭时进入“另存为”。
- Play 前必须拒绝尚未保存的未命名文档；切换项目时不得静默丢弃 dirty 内容。
- 标签当前不支持拖拽排序。

## 终端

- 每个终端标签维护独立 PRoot shell；切换标签不终止后台会话，关闭标签时终止对应会话。
- 终端启动准备失败时显示原因，不创建空终端标签，也不因未捕获异常退出编辑器。只安装基础 rootfs 即可打开普通终端，不要求安装 OMP 和 LuaLS。
- 终端使用 Termux `TerminalView`，底部提供两行快捷键，包括 `ESC`、`TAB`、`CTRL`、`ALT`、方向键、`HOME`、`END`、`PGUP` 和 `PGDN`。
- 首次安装页使用 Toolbar、线性进度和持续追加的日志展示 Ubuntu Base 与工具安装状态；失败后可重试。
- 离线版安装页明确说明完整环境已随 APK 提供，不显示虚假的下载大小；未安装组件固定全选且不可逐项取消，按钮执行整包解压与自检，仍允许跳过后进入编辑器。
- 离线恢复分为解压、配置和自检三个阶段，显示总安装百分比。解压区显示按实际写入字节计算的百分比、已解压/总大小、已处理/总条目数及当前相对路径；长路径居中省略。解压完成后明确显示归档完整性校验，自检显示当前组件和已通过项数，所有自检及安装状态保存成功后总进度才到 100%。已有完整环境直接复用；空间不足、归档损坏或组件自检失败给出错误，失败保留进度详情并允许重试；不完整的既有环境不会被自动清空或覆盖，也不会偷偷改为联网安装。
- 离线仅指环境部署和本地工具可用；OMP/DSH 调用远程模型、下载额外插件和访问远程 Git 仍需联网，不包含模型权重。
- 普通版环境管理提供可选的“LÖVE 11.5 无界面检查”组件，离线版则随完整环境提供；说明其 Linux 11.5 验证边界。安装过程包含真实软件渲染自检，失败时显示安装日志并允许重试，不显示为已就绪。
- 终端、OMP 和 DSH 可通过同一 `love-check` 命令检查项目，不新增 Play 按钮行为或自动保存编辑器缓冲区。用户应先保存文件；检查不弹出游戏窗口，成功也仅表示指定运行片段未捕获到错误。用法见 [verification.md](verification.md#löve-无界面检查)。
- bash-prompt 使用 `PROMPT_DIRTRIM=1`，避免展示完整 `Android/data` 长路径。
- 新建 OMP 标签执行 `omp --allow-home`，不自动继续旧会话；恢复工作区中的 OMP 标签时才追加 `--continue`。从 guest `/root` 启动时保留 `--allow-home`，会话恢复沿用已保存的工作目录。
- guest 主目录提供 `~/projects` 软链接，指向应用的项目根目录；DSH 工作目录选择器可从 Home → projects → 项目进入。升级后首次启动 PRoot 自动补建，不迁移或复制项目；已有同名真实文件或文件夹不会被覆盖。
- DSH Web 标签由应用内后台 PRoot 会话启动；命令使用 `--no-open`，避免调起外部浏览器。应用等待完整启动行中的 loopback 认证 URL 后再加载，不先访问无 token 地址；每个标签独立记录已使用的认证 URL，切换标签不重复提交，URL token 不写入工作区。
- 每次“新建 DSH”都新增标签，不再跳转到已有 DSH 标签；所有标签沿用同一后台服务和认证地址规则。各标签独立保留页面、浏览历史及加载状态，切换不重新创建页面；关闭一个标签不影响其他标签。关闭标签、切换项目或销毁 Activity 时释放对应 WebView。工作区仍只保存标签标题和无 token 基地址，恢复时保留多个 DSH 标签及活动索引，不持久化网页浏览历史或认证 URL。
- WebView 访问 DSH 的 `127.0.0.1:3080` HTTP 服务；API 24+ 明确按该 IP 放行本地 cleartext，API 23 使用 Manifest 兼容开关。服务启动准备失败、WebView 主页面加载失败均显示错误提示。
- DSH profile 自动启用 pnpm `ignore-workspace-root-check=true`；用户可直接执行 `dsh plugin --profile web add <插件>`，不必额外追加 `-w`。预装移动端适配插件为 `dsh-web-mobile`，旧环境在下一次 PRoot 启动准备时补写配置。
- 应用内 WebView 已由 Activity 消费系统状态栏 inset；页面完成后仅清除移动端插件对 `[data-mobile-ux="frame"]` 及其抽屉的重复顶部安全区 padding，不改变网页滚动、输入框或其他布局。
- DSH 标签在等待服务认证地址和 WebView 页面加载时显示顶部不定进度条；完成或失败后隐藏，切换到其他标签时不显示。进度条覆盖在内容区顶部，不改变 WebView 可用高度。
- 游戏窗口遵循 LÖVE/SDL Android 方向规则：`t.window.resizable = false` 且未设置 `SDL_ORIENTATIONS` 时，`width > height` 启动为横屏，`height >= width` 启动为竖屏；`resizable = true` 时允许随设备和系统旋转锁定切换。游戏调试悬浮球在横竖屏双向旋转后停靠到右侧，并按旋转前的纵向比例保持位置，避免落到底部或移出屏幕。
- 游戏调试悬浮球使用黑色半透明背景和白色扳手 Material Symbols，支持拖动。轻触后显示黑色半透明 scrim；横屏面板从左侧滑出，竖屏面板从底部以 Bottom Sheet 形态滑出。调试 Activity 使用 `Window` 的 `adjustPan` 让系统在输入法出现时仅平移到当前输入框可见，不手动计算输入法高度。
- 调试面板标题固定为“调试”，使用 Material 3 游戏主题、纯白背景、少量圆角、大号触控热区和带 Ripple 的 Material 控件。竖屏使用纯图标 `TabLayout`，横屏切换为左侧纯图标 `NavigationRailView`；断点入口使用 `bug_report` 小虫图标，两种导航共享当前页面。控制台日志从内容区顶部开始显示，搜索与等级筛选默认收起；REPL 底部使用单一描边矩形容器，左下角依次提供搜索、筛选、清空和滚动锁定操作，发送位于右下角，右上角可展开多行输入区。监视页使用 `push_pin` 图钉固定安全求值表达式到游戏画面 HUD。REPL 快捷代码和符号栏当前不显示。
- 面板首次显示前先放置到屏幕外，再与 scrim 一同执行入场动画，禁止先绘制最终位置后再设置动画起点。
- Lua 编辑器轻触行号可切换断点，不增加独立 gutter；断点行号背景在亮色主题下为浅红色、暗色主题下为红色。断点按项目持久化到 `.love2droid.json`，编辑导致行数变化时同步迁移，并在 Play 时传入 runtime。游戏断点页不编辑断点，只提供继续、单步和暂停控制、调用栈，以及从 `.love` 快照读取的只读 Lua 编辑器；暂停或单步时高亮当前代码行。
- 监视表达式与固定状态按项目保存在应用私有目录，不进入 `.love` 快照或项目归档；后续每次 Play 自动恢复。面板关闭后固定监视项仍以黑色半透明白字 HUD 显示并持续刷新当前值。所有调试数据通过 native 环形日志缓冲和受保护的 Lua 调试钩子传输；求值错误只进入日志，不终止游戏。


## 项目管理

- 项目管理界面采用现代 MD3 设计规范，背景跟随应用亮暗主题；项目卡片、图标容器、分组标签及筛选 Chip 的普通/选中状态使用 Material 语义颜色。列表显示 `projects/` 下的项目、项目属性中配置的图标（未配置则使用默认图标）、项目名称、分组标签及项目路径。
- 顶部 Toolbar 右上角提供“新建项目”与“导入 .love / .zip”操作；支持按分组筛选（提供“全部”、“未分组”及用户自定义分组 Chip），并支持快速新建分组与管理分组。
- 支持单项长按菜单（重命名、移动到分组、导出为 .love、删除）与多选模式（长按项目可激活多选状态机）。多选模式下顶部切换为操作栏，提供全选/取消全选、批量移动到分组、批量删除及批量导出到下载目录。
- “新建项目”进入独立页面，上方显示“空项目”“基础项目”两个单选模板卡片，下方填写显示名、目录 id、简介和可选分组。默认选中基础项目，延续原有创建内容；不展示尚未实现的模板或占位入口。当前分组筛选会预填到分组字段，全部或未分组筛选则留空。
- 空项目只提供使用 LÖVE 内置字体的 Hello World 入口，不预制字体、`assets/` 和 `AGENTS.md`；两种模板都保留 `conf.lua`、`.luarc.json` 与项目元数据。
- 基础项目沿用原有入口，并离线携带 Fusion Pixel 12px 等宽简中字形 OTF 及许可证，位于 `assets/fonts/`；模板在 `love.load()` 中以 24px 加载，设置字体自身的 `nearest` 过滤，再通过 `love.graphics.setFont` 启用。`AGENTS.md` 说明 Linux LÖVE 11.5 无界面检查与 App 内置 12.0 的版本边界、检查命令及真实结果汇报要求。用户可自行替换字体或字号；不修改已有项目、导入项目和编辑器字体，也不改变后续 `love.graphics.newFont(字号)` 创建的引擎内置字体。
- 新建页面跟随应用亮暗主题，内容可滚动，底部固定“创建项目”按钮并避让输入法。切换模板不清空表单，横竖屏旋转保留选择与输入；名称必填，目录 id 可留空自动生成。创建期间显示进度，禁止重复提交和返回；失败时在页面显示错误并保留输入，成功后直接打开编辑器。未开始创建时返回不生成项目目录。
- 打开或切换项目前先处理当前 dirty 标签。
- 重命名可更新显示名和目录 id；目标目录已存在时拒绝。
- 删除项目需要二次确认并递归删除整个项目目录。
- 项目最近打开时间尚未展示，见 [项目最近打开时间计划](plan/project-recency.md)。

## 语法范围

当前 TextMate 注册覆盖 Lua、Java、Kotlin、JavaScript/TypeScript、Python、HTML、XML、Markdown、JSON、CSS 和 Shell。Lua 是 LÖVE 项目的默认语言；Android 8.0 及以上还通过 LuaLS 提供补全、诊断、悬浮、签名提示、转到定义和查找用法。
